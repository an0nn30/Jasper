# Jasper icon studies — round 1

Six original vector directions for selection, rendered with Inkscape 1.4.4.
Concept artwork only; these files are not wired into application packaging.

Open `comparison.png` for the overview, or any numbered SVG in Inkscape to edit.
Each icon has a 512 × 512 viewBox, transparent outer corners, named layers,
outlined prompt geometry, and no linked images, external assets or font dependencies.
The comparison sheet uses system fonts for its captions.

| Option | Direction |
| --- | --- |
| 1. [Obsidian](01-obsidian.svg) | Quiet graphite. One unmistakable prompt. |
| 2. [Aurora](02-aurora.svg) | Northern light across a midnight screen. |
| 3. [Phosphor](03-phosphor.svg) | Amber glass. A little late-night nostalgia. |
| 4. [Ember](04-ember.svg) | A sculpted prompt cut from warm mineral. |
| 5. [Vector](05-vector.svg) | A floating terminal with architectural depth. |
| 6. [Sumi](06-sumi.svg) | An expressive ink gesture and vermilion cursor. |

The numbered PNGs are 1024px exports. The `-32.png` variants are direct 32px
Inkscape exports. The comparison sheet shows each at 320, 64 and 32px on
light and dark surfaces. Phosphor has an editable SVG blur for its glow;
all other shading is vector gradients and geometry.

Before shipping a selected direction, refine its small-size geometry and
export the platform icon set. The current app icon remains the prior asset.
