# Jasper icon studies — round 5

Six new tab arrangements around the unchanged Frost prompt artwork and colors.
Tabs are larger shapes in the top edge or header, without miniature labels or controls.
The underlying prompt groups are copied intact from round 3, at their original position.

[Comparison sheet](comparison.png) shows 320, 64 and 32px previews.

| Option | Direction |
| --- | --- |
| 1. [Contour](01-contour.svg) | A broad active tab flows into the frame |
| 2. [Slope](02-slope.svg) | Angled tab shoulders and a fine silver rim |
| 3. [Apex](03-apex.svg) | A central active tab between two quiet tabs |
| 4. [Duet](04-duet.svg) | Two full-width tabs within one square frame |
| 5. [Trio](05-trio.svg) | Three broad tabs with the middle one selected |
| 6. [Offset](06-offset.svg) | A raised right tab and a recessed blue-grey tab |

All numbered SVGs are editable in Inkscape and require no fonts or linked images.
512px canvas with transparent outer corners; 1024px and 32px PNG exports included.
Application packaging is unchanged.
