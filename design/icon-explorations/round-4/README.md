# Jasper icon studies — round 4

Six frame and tab treatments around the selected Frost prompt. The prompt paths,
colors, overlap shading and cursor are retained from round 3; Crown, Deck and
Side Rail reposition the intact prompt group to balance their surrounding chrome.
The tabbed-terminal reference informs the concept, while these studies retain
Jasper’s graphite surfaces, silver picture frames and original frame arrangements.

[Comparison sheet](comparison.png) includes 320, 64 and 32px previews.

| Option | Direction |
| --- | --- |
| 1. [Tabline](01-tabline.svg) | An inset tab strip inside the silver frame |
| 2. [Crown](02-crown.svg) | Two raised tabs above a framed terminal |
| 3. [Deck](03-deck.svg) | Layered panes with a quiet blue edge |
| 4. [Side Rail](04-siderail.svg) | Vertical tabs set into the left-hand frame |
| 5. [Index](05-index.svg) | Three small tab markers within the top rim |
| 6. [Keystone](06-keystone.svg) | A central tab clasp on a double silver frame |

All icon artwork is vector, with editable layers and outlined prompt geometry.
No raster assets or fonts are needed. Canvas: 512 × 512 with transparent corners.
Rendered with Inkscape to 1024px and 32px PNGs. Application packaging is unchanged.
