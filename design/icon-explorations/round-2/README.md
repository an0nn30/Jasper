# Jasper icon studies — round 2

Six original SVG variants of the selected Obsidian and Ember directions.
Rendered with Inkscape. Open a numbered SVG to edit the labeled vector layers.
All prompt marks are paths; no fonts, raster images, filters or external assets
are required by the individual icons. Canvas: 512 × 512, with transparent corners.

[Comparison sheet](comparison.png) shows 320px previews and 64/32px comparisons
on light and dark backgrounds. Each icon also has 1024px and 32px PNG exports.

| Option | Direction |
| --- | --- |
| 1. [Platinum](01-platinum.svg) | Classic white prompt · fine silver frame |
| 2. [Cinder](02-cinder.svg) | Pure Obsidian · one warm cursor |
| 3. [Copperline](03-copperline.svg) | Flat copper prompt · matching hairline rim |
| 4. [Forge](04-forge.svg) | Sculpted ember · deep black ground |
| 5. [Bezel](05-bezel.svg) | Ember relief · substantial copper surround |
| 6. [Silvercut](06-silvercut.svg) | Chiseled silver · a copper cursor |

Framed variants: Platinum (fine silver), Copperline (fine copper), Bezel (wide copper).
This is selection artwork; application packaging has not been changed.
