# Jasper icon studies — round 7

[Comparison sheet](comparison.png)

1. [Original Steep](01-steep-original.svg) — unchanged round-six Steep.
2. [Half-height tab](02-steep-half-height.svg) — tab rise reduced from 74 to 37
   viewBox units, with the straight edge retaining its 68-degree slope.

The lower version raises the front shoulder, retaining the same overall icon bounds.
The exposed rear tab height is halved too. The top transition rounding is scaled
with the slope; the rest of the frame, prompt, colors and stroke weight are preserved.

Editable SVGs, 1024px PNGs and 32px PNGs are included. All assets were rendered
with Inkscape. Application packaging is unchanged.
