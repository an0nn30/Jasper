# Jasper icon studies — round 3

Platinum and Cinder are unchanged copies of the selected round-two references.
Four new variants explore the supplied screenshot’s rounded, overlapping prompt:
a light upper arm, a colored lower arm with contact shading, and a rounded cursor.
All four new variants use a subtly tinted picture-frame border on graphite.

[Comparison sheet](comparison.png) includes 320, 64 and 32px previews.

Each SVG is editable in Inkscape, with named layers and outlined geometry.
512 × 512 viewBox, transparent outer corners, no raster assets or font dependencies.
The new artwork uses paths, gradients and clipping; no blur filters.
PNG exports: 1024px and 32px. Comparison captions use system fonts.
Application packaging is unchanged.
