# Jasper icon studies — round 6

Six variations of the selected round-five Slope icon. Only the active tab’s
sloped edge changes. Chevron artwork, colors, gradients, inactive tab, frame
weight, top height, tab drop and the remaining outline are held constant.
The same slight top rounding transitions into each straight slope.

[Comparison sheet](comparison.png) includes 320, 64 and 32px previews.
Angles are measured from horizontal. Option 3 preserves the exact round-five
Slope outline (approximately 57 degrees).

| 2. Steep | 68.0° | [02-steep.svg](02-steep.svg) |

| 5. Wide | 34.0° | [05-wide.svg](05-wide.svg) |
| 6. Extended | 24.0° | [06-extended.svg](06-extended.svg) |

SVGs are editable in Inkscape. Each has a 512px viewBox, transparent corners,
outlined prompt geometry and no external assets or font dependencies.
1024px and 32px PNGs are included. Application packaging is unchanged.
