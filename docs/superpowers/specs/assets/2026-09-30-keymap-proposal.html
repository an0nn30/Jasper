Proposed default shortcuts for every action

Every action in the app and its six plugins, the keys components handle on their own, and the chrome that can't take a shortcut yet. Each row says what changes and why. Reply with the row numbers you want changed.

⌘ is Jasper's on macOS

Every default uses ⌘, with ⇧, ⌥ or ⌃ added. Bare ⌃ and ⌥ keys stay with the shell (Emacs keys, Option as Meta). System keys such as ⌘H, ⌥⌘D and ⇧⌘/ are never used.

Ctrl+Shift in a terminal on Linux and Windows

Terminal and window actions use Ctrl+Shift, as GNOME Terminal and Windows Terminal do, then Ctrl+Alt+Shift. Plain Ctrl, Alt+letter and F1–F10 stay with the shell.

Keys follow focus

An action belongs to a context: Global, Terminal, Editor or one panel. In the Editor and panels, Linux gets plain Ctrl like any editor. The same key can mean different things in different places, and the focused one wins: ⌘R is Shell History in a terminal, Replace in the Editor. A key whose action doesn't apply where focus is goes to the shell instead of being swallowed.

Terminal first, IntelliJ for the rest

Tabs, panes and scrollback follow iTerm2 and Ghostty. The Editor, panels, palette and window chrome follow IntelliJ, which leaves appearance toggles unbound but bindable.

Everything is rebindable

Today's hardcoded Editor keys and the palette-only View toggles become Keymap actions. Keys local to one component (palette, find bar, lists) are listed for completeness.
