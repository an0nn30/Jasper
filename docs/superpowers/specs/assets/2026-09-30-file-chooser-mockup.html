A + preview toggle, in all three modes

Same dialog, three configurations. The preview toggle is the panel button at the right end of the toolbar (highlighted when it's on); the dialog remembers the setting. Check that each mode reads right; details like column choice and spacing can still change.

1 · Open — local, preview on

Opens at the focused terminal's folder, with Terminal folder selected in the pane. Double-clicking a folder enters it, and double-clicking a file (or pressing Enter) opens it. Typing in the File name field accepts a path too (~/x, ../y, an absolute path).

3 · Open — remote host, while connecting

Clicking a host that isn't connected connects to it straight away, with no Connect button. The list shows progress, and a password or key prompt (from the Vault) appears as usual. Once connected, the host shows a green dot and the dialog lands in that host's home folder, or the SFTP folder you last used there. If the connection fails, the same area shows the error and a Retry button.
