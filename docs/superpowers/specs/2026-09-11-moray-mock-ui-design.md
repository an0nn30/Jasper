Reference: `docs/design/mock-ui-reference.png`, unchanged original 1970×1986 screenshot, 144dpi with BenQ RD320UA ICC profile. ## Architecture
Keep WindowContent's real JTabbedPane as the selection/content owner, with a small FlatTabbedPaneUI subclass that overrides protected hideTabArea() and zeroes tab area insets; updateUI reinstalls it on theme changes. Use WRAP layout for the hidden area. Replace old per-tab headers with a separate WindowTabs JPanel of real buttons over that same model; no duplicate TerminalTab/session ownership. WindowTabs refreshes existing entries, rebuilding only on model membership/order changes. WindowContent exposes windowTabs(); non-Mac content hosts it above toolbar, MacTitleBar moves that same component into the native title surface. Current tabStrip() access remains JTabbedPane for model tests.

MacTitleBar remains the app-owned native boundary. For centering controls in the54px title region, add explicit app implementation dependency org.jetbrains.runtime:jbr-api:1.9.0 (already available locally) and use public JBR WindowDecorations.CustomTitleBar on supported macOS. No reflection. Set height before attachment; retain decorated frame. Respect native insets, refresh after peer/layout/fullscreen changes, detach on disposal. Public root properties remain fallback. Native JBR mouse-listener hit testing preserves interactive tabs while empty title space remains draggable. No synthetic traffic lights, no manual window dragging. Native acceptance cannot be claimed from headless tests.

WindowChrome owns toolbar and a focused WindowStatusBar component. AppIcons supplies plain outline assets and dynamic neutral color filters. TerminalPane owns padding and app-specific16px construction defaults. Shared theme resources carry measured dark colors and paired light colors. Palette.morayDark background changes to match measured #292c34; existing ANSI values retained.
