# Dimensional Jasper artwork

Earlier local smooth-art study, 2026-10-19; superseded in the app by [the approved pixel set](../jasper-pixel/README.md). Generated with the built-in image-generation tool using the approved
website character (`website/assets/buddy-dimensional-v1.png`) as its identity and style reference.
The source atlas contains seventeen poses and three sparkle cells; the packed runtime retains the
original three spawn overlays so their placement and compositing contract stay unchanged.

Prompt: create a transparent 5-column × 4-row atlas of the reference turtle, preserving its round olive
head, huge brown glasses, cream segmented belly, brown shell and friendly smile. Match the reference’s
dimensional, pixel-inspired illustration, upper-left highlights and lower-right shading. Keep each
pose in its cell, consistent scale and baseline, without text, background or floor shadows. Row order:
idle, blink, wink, half wave, full wave; hop, lean left, lean right, sit, sit blink; tuck, sleeping shell
with one/two/three Zs, sparkle overlay; two more sparkle overlays, left-hand typing, right-hand typing,
typing rest. Preserve character identity across every pose.

[Sprite maintenance](../../../packaging/buddy/README.md) documents the packing, editable master and
pixel-exact export verification. This earlier study used 168 × 192 source cells.
