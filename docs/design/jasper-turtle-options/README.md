# Jasper turtle icon studies

Three original vector interpretations of the selected turtle mascot, each supplied
as a 1024 × 1024 SVG for macOS (ivory rounded tile) and Windows (transparent silhouette).

- **Explorer:** full turtle with a naturally segmented shell.
- **Desk Buddy:** front-facing portrait with a pale segmented belly.
- **Pocket:** compact turtle with fewer details.

Revised to remove all terminal imagery: Jasper is simply a friendly turtle with glasses.

Open the individual SVGs directly in Illustrator or Inkscape. Artwork consists of
editable paths, rectangles and ellipses with ordinary strokes and named groups.
There are no embedded bitmaps, linked assets, filters or font dependencies in the
six icons. The comparison sheet uses text labels and is a preview only.

`generate.py` reproduces the SVGs and renders PNG previews with the installed
Inkscape CLI. These are design options, not installed application icons or native
ICNS/ICO packages. The existing application assets have not been replaced.
