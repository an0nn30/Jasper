Protean app icon

macOS    macOS/Protean.icns (16-1024, incl. Retina). Protean.iconset is the source for iconutil; rename the "-2x" files to "@2x" before running it.
Windows  Windows/Protean.ico (16, 20, 24, 32, 40, 48, 64, 256). Loose PNGs alongside.
Linux    Copy Linux/hicolor into /usr/share/icons/ (or ~/.local/share/icons/) and install protean.desktop into applications/.
PNG      Flat PNG set, 16-1024.
SVG      Protean.svg master (512 viewBox).
