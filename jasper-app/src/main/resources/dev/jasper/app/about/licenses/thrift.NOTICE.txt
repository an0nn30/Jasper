Apache Thrift 0.23.0 is in the JetBrains Runtime's JCEF twice: as the C++ library linked into the cef_server executable, and as a
copy of the Java runtime inside the jcef module with the package org.apache.thrift renamed to com.jetbrains.cef.remote.thrift
(JetBrains changed three of its files; the README in that package lists them).
Source: https://github.com/apache/thrift, tag v0.23.0.
