# Classic Tango toolbar artwork

Selected, unmodified PNGs from Tango Icon Theme 0.8.90:
https://tango.freedesktop.org/releases/tango-icon-theme-0.8.90.tar.gz

The upstream COPYING file releases these icons into the public domain. The
original COPYING and AUTHORS files accompany this subset. assets.tsv records
original paths and SHA-256 hashes. No runtime download is required.

The 16/32-pixel originals are bundled; Swing renders them at 16/28 logical pixels
and chooses the higher-resolution source for high-density displays.
